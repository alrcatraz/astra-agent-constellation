# Astra Agent Constellation

> **多智能体编排架构蓝图**——单一编排者、位置化执行者、看护者与工具门禁如何组织成一个有序整体。

本蓝图定义一套**可独立验证的多智能体架构约定**：编排关系（谁调用谁、谁维护谁）由规范自行定义，**不依赖任何厂商官方的多智能体框架**（如 DAG/共享内存/角色体系）——模型能力仍经统一网关（如 OmniRoute）获取，执行者实现可替换（如 OpenCode）。将「一个编排者 + 若干个位置化执行者 + 一个看护者 + 一个工具门禁」的组织方式、信息同步规则、纪律传导机制与可观察性要求，写成可供其他团队或机器**采纳与适配**的规范。

## 核心隐喻：星座

`astra` 是「星」。本蓝图把每个智能体看作一颗星，把智能体之间的关系（同步、权限、通信）看作星与星之间的连线——**蓝图就是这张星座图**。其中：

- **编排者（Orchestrator）**——星座的引力中心，唯一的用户交互入口
- **执行者（Executors）**——分布在需要开发/编译/测试平台上的编码智能体
- **看护者（Guardian）**——维护除自己以外所有智能体更新与恢复的辅助智能体（双星模式）
- **工具门禁（Tool Gate）**——所有智能体共用 AI 基础设施的统一入口
