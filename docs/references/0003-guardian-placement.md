# ADR 0003：看护者选址——独立物理机

- 状态：已接受（2026-08）
- 关联章节：[双星模式](../06-gemini-pattern.md)

## 背景

看护者的职责是维护除自己以外所有智能体的更新与恢复。它应该部署在哪里？

## 决策

**看护者 MUST 部署在独立于编排者的物理机上**。截至本版规范，该物理机尚未就位，正在准备中。

## 理由

恢复者不能与被恢复者同机：

- 若看护者与编排者同机，编排者所在机器宕机时，用户**同时失去主智能体和看护者**，「恢复」成为空话。
- 看护者的价值恰恰在编排者不可用时体现；它的存活条件必须独立于编排者的存活条件。

## 被否决的选项

- **与编排者同机（profile 隔离）**：省一台机器，但完全失去双星模式的恢复意义。
- **复用网关机**：候选可行（网关机已独立承载服务），但需确认其不承载本蓝图其他角色的主职责，且物理位置/供电独立。

## 后果

- 看护者部署计划等待独立物理机就位（当前状态：设计完成、待部署）。
- 物理机就位前，编排者直接承担恢复职责（非对称降级，见[双星模式](../06-gemini-pattern.md)第 7 节）。
